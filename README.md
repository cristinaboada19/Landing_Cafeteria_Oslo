# Café Oslo

## Español

Este proyecto es una landing page inspirada en una cafetería ficticia llamada **Café Oslo**. Fue mi proyecto final para un curso de introducción al desarrollo web responsive que hice en Domestika.

Lo subo como parte de mi proceso de aprendizaje y como uno de mis primeros proyectos dentro de mi cambio de carrera hacia el desarrollo web.

## Sobre el proyecto

La idea del proyecto fue maquetar una página web simple, visual y responsive usando HTML, CSS y un poquito de JavaScript para el menú de navegación en versión mobile.

El sitio incluye una cabecera con imagen de fondo, secciones informativas, bloques con íconos, una llamada a la acción, datos de contacto y un footer.

## Tecnologías utilizadas

- HTML
- CSS
- Un poco de JavaScript
- Diseño responsive con media queries

## Qué practiqué con este proyecto

Con este proyecto practiqué varias bases importantes de maquetación web:

- Estructura semántica con HTML
- Estilos generales con CSS
- Uso de imágenes de fondo
- Menú responsive tipo hamburguesa
- Media queries para adaptar el diseño a distintas pantallas
- Organización de secciones
- Uso de floats para crear columnas
- Manejo básico de enlaces, botones y estados hover/active

## Nota sobre el código

Este fue uno de mis primeros proyectos, así que decidí mantenerlo bastante fiel a como lo trabajé durante el curso.

Algunas partes del código usan técnicas que hoy pueden considerarse algo antiguas, como el uso de `float` para armar columnas. El curso que seguí ya tenía bastantes años y todavía no trabajaba con Flexbox o Grid, pero justamente por eso me parece importante conservarlo, ya que muestra el punto desde donde empecé y el proceso real de aprendizaje.

No busqué dejarlo perfecto ni reescribirlo con herramientas más modernas, sino mostrar un proyecto funcional hecho con los conocimientos que tenía en ese momento.

## Estado del proyecto

El proyecto está terminado como práctica inicial.  
Puede tener detalles mejorables, pero funciona correctamente y representa una primera etapa en mi camino aprendiendo desarrollo web.

## Lo que aprendí

Este proyecto me ayudó a entender mejor cómo se construye una página desde cero, cómo se conectan HTML, CSS y JavaScript, y cómo pensar una web para que se vea bien en distintas pantallas.

También me sirvió para ganar confianza, empezar a usar código de forma más ordenada y animarme a seguir aprendiendo nuevas herramientas como Flexbox, Grid y mejores prácticas de desarrollo web.

## English

This project is a landing page inspired by a fictional coffee shop called **Café Oslo**. It was my final project for an introductory responsive web development course I took on Domestika.

I’m uploading it as part of my learning process and as one of my first projects in my career change toward web development.

## About the project

The idea behind this project was to build a simple, visual, and responsive web page using HTML, CSS, and a little bit of JavaScript for the mobile navigation menu.

The site includes a header with a background image, informational sections, blocks with icons, a call to action, contact information, and a footer.

## Technologies used

- HTML
- CSS
- A little bit of JavaScript
- Responsive design with media queries

## What I practiced with this project

With this project, I practiced several important basics of web layout:

- Semantic structure with HTML
- General styling with CSS
- Use of background images
- Responsive hamburger navigation menu
- Media queries to adapt the layout to different screen sizes
- Section organization
- Use of floats to create columns
- Basic handling of links, buttons, and hover/active states

## Note about the code

This was one of my first projects, so I decided to keep it quite faithful to the way I worked on it during the course.

Some parts of the code use techniques that may now be considered a bit outdated, such as using `float` to build columns. The course I followed was already several years old and did not yet work with Flexbox or Grid, but that is exactly why I think it is important to keep it this way, since it shows where I started and the real learning process.

I did not try to make it perfect or rewrite it with more modern tools. Instead, I wanted to show a functional project made with the knowledge I had at that moment.

## Project status

The project is finished as an initial practice project.  
It may have some details that could be improved, but it works correctly and represents a first stage in my journey of learning web development.

## What I learned

This project helped me better understand how a web page is built from scratch, how HTML, CSS, and JavaScript connect with each other, and how to think about a website so it looks good on different screen sizes.

It also helped me gain confidence, start using code in a more organized way, and feel encouraged to keep learning new tools like Flexbox, Grid, and better web development practices.
